# 🧮 Simple Calculator

A simple and user-friendly **Calculator Web Application** built using HTML, CSS, and JavaScript.

This project performs basic mathematical operations through a clean and responsive interface.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal numbers
* 🧹 Clear button
* ⌫ Delete button
* 📱 Responsive design
* ⚡ Fast and lightweight
* 🎨 Simple and clean UI

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling
* **JavaScript** — Calculator functionality

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/simple-calculator.git
```

### 2. Open the Project

```bash
cd simple-calculator
```

### 3. Run

Open `index.html` in your web browser.

You can also use **Live Server** in VS Code.

## 🧮 Operations

The calculator supports:

```text
Addition       +
Subtraction    -
Multiplication ×
Division       ÷
Decimal        .
Clear          C
Delete         ⌫
```

### Example

```text
10 + 5 = 15

20 - 8 = 12

6 × 7 = 42

50 ÷ 5 = 10
```
